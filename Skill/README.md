# AI Skills: Directory & Specifications

This directory contains the operational AI skills utilized across the **Jinder Platform**, packaged according to agent skill standards.

## Shipped AI Skills Catalog

| Skill Name | Path | Purpose |
|---|---|---|
| **Skill Extraction & Normalization** | [`skill-extraction-and-normalization/SKILL.md`](skill-extraction-and-normalization/SKILL.md) | Parses unstructured CV/JD text into verified skills mapped to the Australian ICT Taxonomy. |
| **Capability Gap Analyzer** | [`capability-gap-analyzer/SKILL.md`](capability-gap-analyzer/SKILL.md) | Classifies candidate missing skills into Statutory Blockers vs Learnable Tools and calculates time-to-close. |
| **Formula Engine Calculator** | [`formula-engine-calculator/SKILL.md`](formula-engine-calculator/SKILL.md) | Deterministically computes mathematical models F-01 to F-06 without black-box neural bias. |
| **Zero-PII Anonymizer** | [`zero-pii-anonymizer/SKILL.md`](zero-pii-anonymizer/SKILL.md) | Strips demographic identifiers and assigns unique Australian Wildlife Animal Aliases. |
| **Behavioral Eval Runner** | [`behavioral-eval-runner/SKILL.md`](behavioral-eval-runner/SKILL.md) | Offline behavioral harness for prompt testing, injection resistance, and schema validation (Project-Aegis standard). |
