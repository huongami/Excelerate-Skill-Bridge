# Icons used in the architecture diagrams

| Folder | Source | Terms |
|---|---|---|
| `aws/` | AWS Architecture Icons, from the npm package `aws-icons@3.3.0` (`icons/architecture-service/`, `icons/architecture-group/`) | AWS lets customers and partners use these icons in architecture diagrams. See the AWS Architecture Icons page for the current terms. Do not change the icons. |
| `tools/` | [Simple Icons](https://simpleicons.org/) (`simple-icons`, CC0). The fill color is set to the brand color. | The icons are CC0. The brands (dbt, Terraform, GitHub Actions, PostgreSQL) belong to their owners. |

Apache Iceberg has no icon in these sets. The diagrams show it as a text label.

Note: in this icon set, Amazon QuickSight is named **Amazon Quick Suite** (`AmazonQuickSuite.svg`).
