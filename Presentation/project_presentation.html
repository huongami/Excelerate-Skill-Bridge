Frontend Architecture & Reactive State Engine
Zero-Build Vanilla ES6 SPA • CustomEvent Pub-Sub

The frontend of Jinder is engineered with **Zero-Build purity**. There is no Webpack, Vite, Babel, or NPM node_modules directory. The entire application executes natively in any modern browser via standard ES6 modules, an in-memory Pub-Sub EventBus, and declarative hash routing.

The comparison tray dynamically calculates trigonometric polygon coordinates $(x, y)$ in pure JavaScript and paints native scalable SVG elements:

// Native trigonometry in js/components/radar.js const angle = (Math.PI * 2 * index) / 5 - Math.PI / 2; const x = centerX + Math.cos(angle) * radius * (score / 100); const y = centerY + Math.sin(angle) * radius * (score / 100); points.push(`${x.toFixed(1)},${y.toFixed(1)}`);
Result: Zero bundle weight, instant DOM hydration, and crisp vector rendering across high-DPI displays.
