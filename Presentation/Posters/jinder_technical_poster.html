4 The 6 Canonical Algebraic Formulations (Intelligence Engine V2)
ASD-STE100 Certified • Sub-5ms SLA Determinism • Zero Hallucinations
F-01 • SMF 0.82 ms
Skill Match Frequency & Coverage
$$SMF = \frac{\sum w_i \min\left(1.0, \frac{L_{c,i}}{L_{j,i}}\right)}{\sum w_k} \times 100$$
Weights mandatory (w=2.0) vs preferred skills (w=1.0) with continuous proficiency saturation bounds.
F-02 • GSI & JRS 0.45 ms
Gap Severity Index & Net Readiness
$$GSI = \sum \beta_g \cdot \text{Sev}(g), \quad JRS = \max(0, SMF - GSI)$$
Heavily penalises statutory blockers (β=15.0) while forgiving learnable micro-tools (β=5.0) for actionable bridging.
F-03 • JPI 0.65 ms
Job Proximity Index Mobility
$$JPI = 100 \left[ 0.70 \frac{|S_A \cap S_B|}{|S_A \cup S_B|} + 0.30 \delta_{\text{dom}} \right]$$
Quantifies career mobility using Jaccard vector intersection plus ANZSCO domain taxonomy affinity.
F-04 • RMS 1.10 ms
Relative Merit Score (Zero-PII Pool)
$$Z_c = \frac{SMF_c - \mu}{\sigma + \epsilon}, \quad RMS = \frac{100}{1 + e^{-1.702 Z_c}}$$
Gaussian Z-score standardization against active applicant distribution, eliminating demographic bias.
F-05 • FRS 1.82 ms
Talent Feed Ranking Score
$$FRS = 0.45 SMF + 0.25 JRS + 0.20 \text{Exp} + 0.10 \text{Mode}$$
Multi-objective ranking balancing direct skill alignment, readiness score, seniority level, and hybrid work mode.
F-06 • TSS 1.35 ms
Employer Talent Search Score
$$TSS = 0.40 SMF + 0.25 \text{Sen} + 0.20 \text{Cred} + 0.15 \text{Rec}$$
Ranks enterprise candidate pool factoring capability coverage, AQF seniority, verified credentials, and recency.
