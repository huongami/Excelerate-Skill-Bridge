# Presentation Directory

This directory contains the interactive presentation decks and mathematical architecture presentations for the **Jinder Platform**, styled according to the modern Jinder Design System (Deep Navy, Violet Gradient, Coral Accent).

## HTML Presentations

| File | Type | Description |
|---|---|---|
| [**`project_presentation.html`**](project_presentation.html) | Interactive Pitch Deck | Full project presentation covering problem definition in Australia, two-sided platform architecture, ethical AI principles, and live platform launch. |
| [**`formulas_presentation.html`**](formulas_presentation.html) | Mathematical Engine & Formulas | Interactive ASD-STE100 technical presentation with live parameter sliders, KaTeX mathematical formulas, step-by-step worked numerical examples for F-01 to F-06. |

---

## Viewing Instructions
Both presentations are standalone HTML5 applications with zero required build steps. Open directly in any modern browser:
- `open Presentation/project_presentation.html`
- `open Presentation/formulas_presentation.html`
