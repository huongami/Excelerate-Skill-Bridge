Enterprise Medallion Lakehouse Pipeline Architecture

This enterprise data platform implements the Medallion Lakehouse Architecture, combining Apache Spark for near real-time stream ingestion and PII anonymization, dbt Core for modular SQL transformations and contract validation, Apache Airflow for orchestration, and DuckDB / Parquet for high-speed analytical queries. Data progresses systematically across five stages: raw ingestion, schema conformance, ANZSCO occupational classification, candidate-job capability scoring, and serving.

Core Pipeline Architecture & Layer Specifications

🥉 Bronze Layer: Ingestion & Raw Landing

Handles asynchronous ingestion from live Adzuna Australian job vacancy streams and global candidate resume feeds. Records are stored append-only with streaming checkpoints to preserve payload fidelity and enable seamless recovery without data loss or duplicate records.

🥈 Silver Layer: Anonymization & Conformance

PySpark detects and masks Personally Identifiable Information (Emails, Phone Numbers, Passport IDs) using one-way SHA-256 tokens. Australian salary ranges, state locations, and dates are normalized into standardized columns and persisted as Snappy-compressed columnar Parquet datasets.

🔄 dbt Layer: Taxonomy Mapping & Data Contracts

dbt Core manages modular SQL transformations across Staging views, Intermediate taxonomy models (cross-walking candidate job roles to Australian Bureau of Statistics ANZSCO occupation codes), and automatically validates compile-time data quality contracts (unique, not_null, accepted_values).

🥇 Gold & Serving Layer: Capability Matrix & Analytics

Maintains production analytical marts: fct_capability_alignment_matrix (deep skill overlap scores between international talent and Australian employers) and dim_australian_market_demand (demand and salary metrics across 8 sectors), served via DuckDB with query execution under 6ms.
